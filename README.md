# Chido Madiren — Full-Stack Software Developer Portfolio

A magnificent, high-performance personal portfolio built with **React**, **Vite**, and **Tailwind CSS**. Designed with a minimalist monochrome aesthetic, smooth micro-animations, and interactive state controls.

---

##  Features

- **Chichie Bridal & Chichie Saloon**: Beauty and bridal web applications with service catalogs, styling grids, and booking flows.
  - **MyRecipe Full-Stack**: Complete recipe management platform with user authentication, CRUD operations, and PostgreSQL persistence.
  - **FoodWebsite React**: Responsive culinary frontend with dynamic menu layouts and interactive UI components.
  - **Madiren Academy**: Educational portal and course dashboard with streamlined student workflows.
- **Certificate Inspector Modal**: Interactive credential cards with verification IDs and detailed summaries.
- **Download cv button**

---

##  Tech Stack

- **Frontend Framework**: React 18+ (Vite)
- **Styling**: Tailwind CSS & PostCSS
- **Typography**: Inter & JetBrains Mono (Google Fonts)
- **Version Control**: Git & GitHub
